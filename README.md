# StudyTask - organização acadêmica
## Descrição
  O StudyTask é um aplicativo de organização acadêmica voltado, principalmente, para estudantes no geral (escola, universidade, mestrado...).
   
   O sistema tem como objetivo centralizar tarefas, disciplinas, e materiais de estudo em uma única plataforma.
## Funcionalidades
-- Cadastro de login e usuários;

-- Cadastro de disciplinas;

-- Cadastro de tarefas;

-- Definição de prioridades;

-- Controle do andamento das tarefas;

-- Organização de arquivos em pastas;

-- Download e acesso aos materiais;
